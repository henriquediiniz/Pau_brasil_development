Líder Itinerante

Configura sua foto de referência uma única vez e faz check-in sempre que visita uma filial.

Setup inicial — feito uma única vez
1
Popular as filiais no banco Uma vez
Execute este comando no terminal do servidor para cadastrar as 8 filiais (Patos, Sousa, Itaporanga, Sumé, Guarabira, Brumado, Barra da Estiva, Caculé): npx ts-node prisma/seed-operations.ts Depois disto, nunca mais precisa rodar. As filiais ficam permanentemente no banco.
2
Ativar o líder itinerante no colaborador Admin
Acesse /admin/usuarios, encontre o colaborador e clique em Editar (lápis). Na seção Módulos especiais, ative Líder Itinerante. Um campo aparece para preencher o cargo (ex: CFO, Diretora de Gente). Salve. O colaborador verá o menu Visitas no próximo login.
3
Configurar foto de referência Uma vez por líder
O próprio líder acessa /app/visitas/configurar-face pelo portal.

Passo a passo:
1. Clicar em Abrir câmera (modelos de IA carregam em ~5s)
2. Posicionar o rosto centralizado, em ambiente bem iluminado
3. A captura é automática quando o rosto é detectado
4. A foto é salva e vinculada ao perfil — pode refazer quantas vezes quiser

Fazer check-in — uso diário do líder
1
Acessar a página de check-in Cada visita
No menu lateral do portal, clique em Visitas → Check-in. Isso abre o check-in para a filial de Patos. Para outras filiais, acesse diretamente pela URL: /app/visitas/checkin/sousa (veja a tabela de filiais abaixo para os slugs corretos)
2
Fase 1 — Validação de GPS
O navegador pede permissão de localização — aceite. O sistema verifica se você está dentro do raio de 200 metros da filial.

✅ Dentro do raio → avança para a câmera
🟠 Fora do raio → tela laranja mostra a distância exata em metros
3
Fase 2 — Reconhecimento facial
A câmera frontal abre automaticamente. Olhe diretamente para a lente, de frente e em ambiente iluminado. O check-in é feito automaticamente quando o rosto corresponde à foto de referência cadastrada.

Não é preciso apertar nenhum botão — basta olhar para a câmera.
4
Fase 3 — Confirmação
Tela verde com ✅ Check-in realizado! — a visita foi registrada. Você pode ver o histórico completo em /app/visitas/lider/[seu-id] ou clicando em Ver histórico.
Status de cada visita
Válida
GPS e reconhecimento facial aprovados. Visita registrada com sucesso.
GPS inválido
O líder estava fora do raio de 200m da filial. A tentativa é registrada mas não conta como visita.
Face inválida
GPS ok, mas o rosto não foi reconhecido. Pode ser iluminação ruim ou foto de referência desatualizada.

Dashboard administrativo
🔍
Acessar o dashboard Somente Sys Admin
Acesse /app/visitas/dashboard ou pelo menu Visitas → Dashboard Visitas.

Você pode filtrar por:
  • Líder — ver visitas de um líder específico
  • Filial — ver todas as visitas a uma unidade
  • Mês — filtrar por período
  • Status — válidas, GPS inválido ou face inválida
Dicas e resolução de problemas
💡
Iluminação ruim: O reconhecimento facial precisa de boa iluminação. Se a detecção falhar, peça ao líder para ir a um ambiente mais claro antes de tentar novamente.
🔄
Foto de referência desatualizada: Se o líder mudou muito de aparência (barba, óculos, cabelo), acesse /app/visitas/configurar-face e refaça a foto de referência clicando em Refazer foto.
📡
GPS impreciso em prédios: O raio de 200m já leva isso em conta. Se o líder estiver claramente dentro da filial mas o GPS não validar, o raio pode ser ajustado por filial via Prisma Studio no campo radiusMeters.
🔐
Usuário não vê o menu Visitas: O Sys Admin precisa ativar Líder Itinerante no cadastro do usuário. Após salvar, o colaborador precisa fazer logout e login novamente para o token atualizar.
📱
Melhor experiência: Use o celular, não o desktop. Câmera frontal + GPS são mais precisos no dispositivo móvel.
