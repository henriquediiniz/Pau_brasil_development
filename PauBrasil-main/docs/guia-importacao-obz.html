🌿 Guia de Importação em Lote — OBZ 2026

Grupo Pau Brasil · Portal OBZ · Documento interno para analistas

Abr/2026

Visão Geral — Sequência obrigatória de importação

Rodada 1
📊 Orçado (Metas Anuais)
Importar as metas Jan–Dez para todas as linhas de custo.
Deve ser feito primeiro — é a base de comparação.
Rodada 2
💰 Real (Jan, Fev, Mar)
Importar o realizado dos primeiros 3 meses.
Somente após o orçado estar salvo.
Rodada 3
📈 Tendência Abril
Responsabilidade dos donos de pacote.
Lançam diretamente no portal /obz.

0 Pré-requisito — Criar os Períodos de 2026

Antes de qualquer importação, o administrador precisa criar os períodos mensais no sistema.

  1. Acesse Admin → OBZ → aba Períodos
  2. Crie os períodos de Janeiro a Dezembro/2026
  3. Marque Jan, Fev e Mar como abertos (permite importar o real)
  4. Marque Abril como aberto também (para os donos lançarem tendência)
⚠️ Sem os períodos criados, a importação do Real será rejeitada pelo sistema.

1 Rodada 1 — Importar o Orçado (Metas Anuais)

1.1 — Baixar o template

  1. Acesse Admin → OBZ → aba Importação
  2. Selecione Tipo = Orçado e Ano = 2026
  3. Clique em Baixar Template
  4. O arquivo OBZ_Orcado_2026.csv será baixado — abra no Excel

1.2 — Estrutura do arquivo

areaPacoteId linhaId Pacote Área Operação Linha de Custo Jan Fev … Dez
Não editar Não editar Referência Referência Referência Referência Preencher Preencher … Preencher
ℹ️
Regras de preenchimento:
• Use vírgula para decimal: 1.500,00 (formato BR) ou 1500.50 (formato Excel)
• Células vazias ou com zero são ignoradas automaticamente
• Linhas sem orçamento podem ser deletadas do arquivo
• Nunca altere as colunas areaPacoteId e linhaId — são chaves internas do banco

1.3 — Importar

  1. Salve como .xlsx ou CSV separado por ponto e vírgula
  2. Volte para Admin → OBZ → aba Importação
  3. Selecione Tipo = Orçado, Ano = 2026, anexe o arquivo
  4. Clique em Importar
  5. O sistema exibirá o resumo: quantos registros foram importados e eventuais erros
✅ A importação pode ser repetida quantas vezes necessário — o sistema atualiza os valores existentes sem duplicar.

2 Rodada 2 — Importar o Real (Jan, Fev e Mar)

2.1 — Baixar o template de Real

  1. Na mesma tela, selecione Tipo = Real e Ano = 2026
  2. Clique em Baixar Template
  3. O arquivo OBZ_Real_2026.csv já vem pré-preenchido com os valores do orçado como referência e exibe apenas as colunas dos meses abertos (Jan, Fev, Mar)

2.2 — Preencher

  1. Substitua os valores de Jan, Fev e Mar com o realizado de cada linha de custo
  2. Colunas de meses futuros (Abr em diante) podem permanecer em branco
  3. Não altere as colunas de identificação (areaPacoteId, linhaId)

2.3 — Justificativas automáticas

⚠️
Quando o real importado for maior que o orçado, o sistema cria automaticamente uma justificativa pendente para o gestor revisar. Isso é esperado e correto — o gestor simplesmente aprova ou reprova a justificativa depois.

2.4 — Importar

  1. Mesmos passos da Rodada 1, selecionando Tipo = Real
  2. O resumo mostrará quantas justificativas foram geradas automaticamente

3 Rodada 3 — Donos Lançam a Tendência de Abril

Após as Rodadas 1 e 2, cada dono de pacote realiza os lançamentos de tendência diretamente no portal:

  1. Acessa /obz no portal
  2. Verá os cards dos seus pacotes com o badge "Tend. Abr: 0/X" (pendente)
  3. Clica no card → lança a tendência linha a linha para Abril
  4. Se a tendência diferir do orçado, o sistema solicita uma justificativa
📣
O administrador pode acionar Admin → OBZ → aba Tendência → botão "Notificar pendentes" para enviar notificação no sistema a todos os donos que ainda não realizaram o lançamento.

✦ Dicas Importantes

📋 Ordem correta Sempre importar Orçado antes do Real. O sistema usa o orçado como referência para gerar justificativas automáticas quando o real supera a meta.
📁 Formatos aceitos O sistema aceita .xlsx, .xls e .csv. Não é necessário converter — pode importar direto do Excel.
🔄 Reimportação segura Pode reimportar o mesmo arquivo quantas vezes precisar para corrigir valores. O sistema atualiza os registros sem duplicar.
🔑 Colunas de ID Nunca edite areaPacoteId nem linhaId. São chaves internas — qualquer alteração fará a linha ser rejeitada na importação.
❌ Erros na importação Se uma linha tiver erro, as demais são salvas normalmente. O resumo pós-importação lista cada linha com erro e o motivo.
🔢 Formato numérico Use vírgula como decimal (1.500,00) ou ponto (1500.50). Ambos são aceitos. Valores negativos são rejeitados.
