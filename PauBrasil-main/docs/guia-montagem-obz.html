Antes de começar, é essencial entender como os dados são organizados no sistema. A hierarquia é:

🏛 Estado (ex: Bahia)
🏢 Operação (ex: Eunápolis)
📁 Departamento (ex: Financeiro)
🔗 Pacote "Pessoal" › Linha "Salários" — Responsável: João Silva
🔗 Pacote "Despesas" › Linha "Combustível" — Responsável: Maria Souza
🏢 Operação (ex: Porto Seguro)
📁 Departamento (ex: Operacional)
🔗 Pacote "Manutenção" › Linha "Peças" — Responsável: Carlos Lima
ℹ️
Pacotes são globais. Um mesmo Pacote (ex: "Pessoal") pode ser atribuído a vários departamentos em operações diferentes. As Linhas de Custo dentro do pacote são compartilhadas. O que varia por departamento é o Responsável e os valores lançados.

⚠️
Usuários precisam existir antes da importação. Se o e-mail do responsável não estiver cadastrado no sistema, a linha é ignorada com aviso. Crie os usuários em Admin → Usuários primeiro, depois volte aqui.
💡
Pode importar em partes. A importação é idempotente — pode ser executada várias vezes sem duplicar dados. Se um usuário ainda não existe, importe o restante agora e reimporte depois completando as linhas com e-mail. Nunca perde o que já foi criado.

Caminho Rápido — Import CSV Único

🚀
Use esta opção sempre que possível. Um único arquivo CSV monta toda a estrutura automaticamente — estados, operações, departamentos, pacotes, linhas, atribuições com responsável e códigos contábeis. Elimina todo o trabalho manual das etapas 2 a 5.
Como usar:
  • Acesse Admin → OBZ → aba Importação.
  • Na seção "Importar Estrutura Completa", clique em Baixar template.
  • Preencha o CSV seguindo o modelo. Cada linha representa uma atribuição:
estado;operacao;departamento;pacote;linha_pai;linha;responsavel_email;codigo_contabil
Bahia;Eunápolis;Financeiro;Pessoal e Encargos;Pessoal Próprio;Salários;joao@grupopaubrasil.com.br;4140101
Bahia;Eunápolis;Financeiro;Pessoal e Encargos;Pessoal Próprio;Férias;joao@grupopaubrasil.com.br;4140102
Bahia;Eunápolis;Operacional;Manutenção;Veículos;Combustível;maria@grupopaubrasil.com.br;4140601
  • Salve como .csv com separador ponto e vírgula (;).
  • Faça upload e clique em Importar Estrutura.
  • Verifique o resultado: o sistema mostra quantos registros foram criados por nível e avisa sobre e-mails não encontrados.
💡
Salvando no Excel com separador correto:
  1. Após preencher a planilha, vá em Arquivo → Salvar Como.
  2. Em "Tipo", escolha CSV (separado por vírgulas) (*.csv).
  3. Se o seu Excel estiver em PT-BR, ele usa ponto e vírgula (;) automaticamente — é o formato correto.
  4. Se estiver em EN-US, após salvar abra o arquivo no Bloco de Notas e substitua as vírgulas por ponto e vírgula antes de importar.

As etapas 2 a 5 abaixo descrevem como criar a estrutura manualmente pela UI, caso necessário para ajustes pontuais ou complementações.

0

Pré-requisitos — Usuários e Acessos

Antes de montar a estrutura, confirme que os usuários que serão responsáveis pelos pacotes já existem no sistema e têm o e-mail correto cadastrado.

  • Acesse Admin → Usuários e verifique se todos os responsáveis estão cadastrados e com status Ativo.
  • O usuário precisa ter ao menos o perfil básico. Não precisa ser OBZ Admin para ser responsável por um pacote.
  • Anote os nomes completos — eles serão selecionados no campo Responsável durante a atribuição.
⚠️
Usuário inativo ou inexistente = impossível atribuir pacote. Se o responsável não aparecer na lista durante a atribuição, verifique o status do usuário em Admin → Usuários.
1

Como Acessar o Painel Admin do OBZ

  • Faça login com um usuário que tenha a flag OBZ Admin habilitada (ou SYS_ADMIN).
  • No menu lateral, acesse Admin → OBZ.
  • Você verá as abas na parte superior: Estrutura · Pacotes · Períodos · Importação · Tendência · Manutenção.
💡
A ordem recomendada para montar do zero é: Pacotes → Estrutura → Atribuições → Período Anual → Períodos Mensais. Siga essa sequência para evitar ter que voltar.
2

Criar Pacotes Globais e Linhas de Custo

Aba: Pacotes

Pacotes são as categorias de custo (ex: Pessoal, Manutenção, Despesas Administrativas). Cada pacote tem uma hierarquia de linhas de custo.

Criar um Pacote:
  • Clique no botão + Novo Pacote no topo da aba.
  • Preencha o campo Nome do Pacote (ex: "Pessoal e Encargos").
  • Clique em Salvar. O pacote aparece na lista.
Criar Linhas de Custo dentro do Pacote:
  • Com o pacote criado, clique na seta ▶ para expandir.
  • Clique no ícone + ao lado do pacote para adicionar uma linha-pai (ex: "Pessoal Próprio").
  • Para criar uma sublinha, expanda a linha-pai e clique no + ao lado dela (ex: "Salários", "Férias", "13º").
  • Repita o processo para todas as linhas necessárias em cada pacote.
Exemplo de estrutura de pacote:
📦 Pessoal e Encargos
   └─ Pessoal Próprio
       ├─ Salários
       ├─ Férias
       └─ 13º Salário
   └─ Encargos
       ├─ INSS
       └─ FGTS
⚠️
Os lançamentos (orçado, real, tendência) são feitos sempre nas linhas-folha — as linhas mais internas que não têm filhas. Linhas-pai são apenas agrupadores. Planeje a hierarquia com isso em mente.
3

Montar a Hierarquia Organizacional

Aba: Estrutura

Aqui você cria a estrutura Estado → Operação → Departamento que reflete a organização da empresa.

3.1 — Criar Estado:
  • Clique em + Novo Estado.
  • Informe o nome (ex: "Bahia", "São Paulo", ou o nome da unidade de negócio).
  • Clique em Salvar. O estado aparece na lista.
3.2 — Criar Operação dentro do Estado:
  • Expanda o Estado clicando na seta ▶.
  • Clique no ícone + ao lado do estado para adicionar uma Operação.
  • Informe o nome da operação (ex: "Eunápolis", "Porto Seguro").
3.3 — Criar Departamento dentro da Operação:
  • Expanda a Operação clicando na seta ▶.
  • Clique no ícone + ao lado da operação para adicionar um Departamento.
  • Informe o nome do departamento (ex: "Financeiro", "Operacional", "RH").
💡
Dica — Duplicar: Se uma operação tiver a mesma estrutura de departamentos que outra, use o ícone ⎘ (Duplicar) ao lado da operação para copiar todos os departamentos de uma vez. Selecione o estado de destino na janela que abre.
4

Atribuir Pacotes aos Departamentos

Aba: Estrutura

Esta é a etapa mais importante. Aqui você define qual pacote (e qual linha dentro dele) o departamento vai controlar, e quem é o responsável (dono) pelos lançamentos.

  • Expanda o Departamento clicando na seta ▶.
  • Clique no ícone 🔗 (Atribuir Pacote) ao lado do departamento.
  • Na janela que abre, selecione o Pacote desejado (ex: "Pessoal e Encargos").
  • Selecione a Linha que representa o "pacote" no contexto do departamento — geralmente uma linha-pai que agrega todas as sublinhas do departamento.
  • Selecione o Responsável (usuário que vai lançar os valores).
  • Clique em Salvar. A atribuição aparece indentada abaixo do departamento.
⚠️
Um departamento pode ter múltiplos pacotes atribuídos. Repita o passo 4 para cada pacote/linha que aquele departamento controla. Cada atribuição pode ter um responsável diferente.
✅
Como validar: Após criar a atribuição, expanda o departamento. Você deve ver a linha no formato:
NomePacote › LinhaParent › Linha — NomeResponsável
💡
Para muitas atribuições ao mesmo tempo, use o CSV. A aba Importação → "Importar Estrutura Completa" cria todas as atribuições de uma vez. O preenchimento manual acima é indicado apenas para ajustes pontuais após a importação inicial.
5

Abrir o Período Anual

Aba: Períodos

O período anual controla se o orçado pode ser importado. Precisa estar aberto para qualquer importação de orçado funcionar.

  • Acesse a aba Períodos.
  • Selecione o ano corrente no seletor de ano (ex: 2026).
  • Clique em Abrir Período Anual 2026.
  • Confirme a operação. O status deve mudar para Aberto.
ℹ️
O período anual pode ser travado após a importação do orçado para impedir alterações. Apenas OBZ Admin consegue importar com o período travado. Não trave agora — faça isso apenas depois de validar todos os valores importados.
6

Abrir Períodos Mensais

Aba: Períodos

Os períodos mensais controlam quando os responsáveis podem lançar valores reais para aquele mês. A tendência tem controle separado.

  • Na aba Períodos, você verá os 12 meses do ano.
  • Clique no mês desejado para alternar entre Aberto e Fechado.
  • Abra apenas os meses que já devem receber lançamentos reais.
PeríodoQuando abrirQuem pode lançar com período fechado
Período anualAntes da importação do orçadoOBZ Admin
Período mensalNo início de cada mês de competênciaOBZ Admin

✓

Checklist Final de Validação

Antes de liberar o sistema para os responsáveis, confirme cada item abaixo:

  • Todos os usuários responsáveis existem no sistema com e-mail correto e status Ativo
  • A importação CSV foi executada sem erros (avisos de e-mail inexistente foram resolvidos)
  • Todos os departamentos têm ao menos uma atribuição (pacote + linha + responsável)
  • O período anual está aberto (ou travado, se o orçado já foi importado)
  • Os períodos mensais corretos estão abertos
  • Ao acessar OBZ → Meus Pacotes como um responsável, os pacotes atribuídos aparecem corretamente
  • O admin consegue ver os departamentos no painel Admin → OBZ → Estrutura com as atribuições listadas
  • Se usou códigos contábeis: conferir em um pacote se o campo Código contábil está preenchido nas linhas-folha
🚀
Pronto para uso. Com o checklist completo, os responsáveis já podem acessar o sistema, baixar o template de orçado/tendência/real e fazer seus lançamentos normalmente.
